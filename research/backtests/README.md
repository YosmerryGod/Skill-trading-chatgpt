# Backtest Reports

Store one report per fixed rule and version.

Reports must state:
- Rule definition and version.
- Dataset period, symbols, and timeframes.
- Chronological signal timing and candle completion assumptions.
- Duplicate-signal handling.
- Outcome horizon and metrics.
- Baseline and out-of-sample results.
- Failed cases, missed events, and sensitivity checks.

Follow [skill-backtesting.md](../../skills/skill-backtesting.md). Do not present in-sample performance as independent validation or guaranteed future results.
