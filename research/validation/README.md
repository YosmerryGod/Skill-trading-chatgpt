# Validation Reports

Store one report per hypothesis and version.

Each report must reference:
- Fixed hypothesis definition.
- Discovery and untouched validation periods.
- Independent sample IDs.
- Success/failure definitions and evaluation horizon.
- Baseline comparison.
- False positives, missed events, and counterexamples.
- Limitations and final status.

Use the workflow in [skill-validation.md](../../skills/skill-validation.md). Never overwrite a previous report after changing the hypothesis; create a new version.
