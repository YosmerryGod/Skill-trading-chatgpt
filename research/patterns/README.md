# Pattern Records

Store one Markdown record per pattern ID, using the format in [skill-pattern-library.md](../../skills/skill-pattern-library.md).

Each pattern record should include:
- Exact, versioned definition.
- Timeframe, baseline, and detection timestamp.
- Supporting sample IDs.
- Counterexample sample IDs.
- Validation and backtest references.
- Current status and limitations.

A pattern is not a validated signal merely because it appears visually similar across charts.
